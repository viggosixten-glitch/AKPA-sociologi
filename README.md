# AKPA Sociologi – Nivåstegen

Tentaträning i Duolingo-stil för delkursen Arbetsmarknadssociologi (AKPA 1, SU). Tenta 27 november 2026.

- Ett stopp per föreläsning (grund → begrepp i fall → tentanivå) och en blandad tentarunda
- Dagens pass: dagligt mål räknat mot tentadatum, svaga punkter först
- Tentasimulering: cirka 70 p, tidtagning, inget facit förrän efteråt, motivering ger bara poäng om sant/falskt var rätt
- Extra träning: frågor från tentan 24/25
- Samma frågetyper som tentan: flerval, flersvar, para ihop, placera på skala, lucktext, sant/falskt med motivering
- Fel kommer tillbaka i slutet av omgången, svaga punkter visas med hänvisning till källan

Allt innehåll ligger i `index.html` under `KURSDATA`. Öppna filen i en webbläsare eller via GitHub Pages.
